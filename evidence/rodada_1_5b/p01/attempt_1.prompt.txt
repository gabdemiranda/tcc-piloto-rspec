Com zero caixas o resultado é 0, qualquer que seja a umidade. Com ao menos uma caixa, o tempo de espera é 12 minutos mais 4 minutos por caixa. Some 9 minutos se a umidade for maior ou igual a 70. module TriagemDeAcervo
  class JanelaDeAclimatacao
    def self.minutos(caixas, umidade)
      return 0 if caixas < 1
      espera = 12 + caixas * 4
      espera += 9 if umidade >= 70
      [espera, 45].min
    end
  end
end
